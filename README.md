# Data Visualization Project

## Overview
This project explores how various lifestyle factors influence a female's likelihood of developing coronary diseases. The analysis focuses on visualizing relationships and correlations between lifestyle choices and health outcomes. This was completed as the term project for a data visualization course, utilizing Python for analysis and Power BI for interactive reporting.

## Repository Contents
*   **`DSCI 2411 Project Python Code.ipynb`**: The Jupyter Notebook containing the Python code for data manipulation and visualization.
*   **`Project Power BI.pbix`**: The Power BI file with interactive dashboards and reports.
*   **`DSCI 2411 Project Report.pdf`**: The final project report detailing the methodology, visualizations, and findings.
*   **`Project.Data.Females.csv`**: The dataset used for the analysis.

## Key Questions Explored
*   How do factors like **education level** and **social class** correlate with coronary disease risk?
*   What is the impact of **diet, exercise, smoking, and drinking habits** on the likelihood of developing coronary diseases?
*   Which lifestyle factors show the strongest correlations with health outcomes?

## Tools and Techniques
*   **Python**: For data manipulation and initial analysis.
    *   `Pandas`: For data cleaning, transformation, and aggregation.
    *   `Matplotlib` & `Seaborn`: For creating static visualizations (e.g., bar charts, scatter plots, heatmaps).
*   **Power BI**: For building interactive dashboards and summarizing key insights.
*   **Analysis**: Exploring relationships and correlations between lifestyle variables and coronary disease incidence.

## How to Reproduce This Work
1.  Clone this repository to your local machine.
2.  Ensure you have Python and Jupyter Notebook installed, along with the required libraries (`pandas`, `matplotlib`, `seaborn`).
3.  Open and run the `DSCI 2411 Project Python Code.ipynb` notebook.
4.  To view the interactive dashboard, open the `Project Power BI.pbix` file using Microsoft Power BI Desktop.
